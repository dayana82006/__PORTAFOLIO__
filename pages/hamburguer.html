HAMBURGUER PLUS

Hamburguer Plus es una página web creada con un enfoque minimalista y funcional, desarrollada exclusivamente con HTML y CSS puro. Este proyecto busca destacar la importancia de los fundamentos en el desarrollo web, mostrando cómo se puede lograr un diseño atractivo y funcional sin depender de frameworks o herramientas externas.

Tecnologías utilizadas

HTML

Es el lenguaje de marcado que estructura y define el contenido de una página web

CSS

CSS es el lenguaje que se encarga de la apariencia y el diseño de una página web.

VisualStudio

Es un editor de texto diseñado para programar de manera eficiente.

Beneficios y Características

Interfaz Intuitiva

Hamburguer Plus tiene una interfaz simple que permite personalizar hamburguesas y realizar pedidos de forma rápida y fácil.

Optimización en pc

El sitio está optimizado para dispositivos de escritorio, garantizando una navegación fluida y un diseño adaptado a pantallas grandes.
