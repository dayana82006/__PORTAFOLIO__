
# 🎨 **Portafolio Web de Dayana Hernández** 🚀


¡Bienvenido a mi proyecto! Este repositorio contiene un **portafolio web** creado con **HTML, CSS, JavaScript** y el framework **Bootstrap**. Es un espacio donde muestro mis habilidades, proyectos y pasión por el desarrollo y la creatividad.  

---

## 🛠️ **Tecnologías Utilizadas**  

- **HTML**: Para la estructura y el contenido de la página.
- **CSS**: Para los estilos visuales y la maquetación.
- **JavaScript**: Para la interactividad y las animaciones.
- **Bootstrap**: Framework para crear un diseño responsive y adaptativo.
- **AOS (Animate On Scroll)**: Librería para agregar animaciones a la página cuando el usuario hace scroll.
- **Devicon**: Para mostrar los íconos de las tecnologías utilizadas.

---

## 🎯 **Objetivo del Proyecto**  
Desarrollar un **portafolio web dinámico y responsivo** que permita:  
- Presentar mis **habilidades y proyectos destacados**.  
- Mostrar una **navegación intuitiva** y una interfaz **atractiva**.  
- Adaptarse a cualquier dispositivo gracias al uso de **Bootstrap** y complementos con propio css.  

---
## 🚀 Características

- **Interfaz Intuitiva**: El diseño es simple y claro, lo que facilita la navegación por el portafolio.
- **Responsive**: El portafolio se adapta a diferentes tamaños de pantalla (móviles, tabletas, computadoras).
- **Animaciones**: Se usan animaciones sutiles para mejorar la experiencia del usuario mientras navega por el sitio.
- **Sección de Proyectos**: Muestra los proyectos más importantes en los que he trabajado, con una breve descripción y las tecnologías utilizadas.
- **Sección de Contacto**: Incluye enlaces a mis redes sociales y detalles para contactarme.
